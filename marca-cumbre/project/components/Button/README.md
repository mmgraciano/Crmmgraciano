Botón de acción en cuatro variantes: `primary` (pizarra), por defecto (contorno), `quiet` (enlace) y `danger` (lacre).

- Provee: `<button class="cu-btn primary">` con un verbo que diga qué pasa ("Registrar mandato", "Exportar Excel").
- Un solo `primary` por pantalla o diálogo.
- `danger` solo para acciones que no se deshacen (revocar, eliminar) y siempre con un paso de confirmación.
- No: íconos solos sin texto, mayúsculas sostenidas, signos de exclamación.
