Etiqueta de estado de un mandato, cliente o tarea, con un marcador cuadrado y una palabra.

- Provee: `<span class="cu-badge ok|warn|lacre|firmado">` y el texto del estado.
- Estados: neutro (En revisión), `ok` (Conforme, Al día), `warn` (Pendiente, Vence en N días), `lacre` (Vencido, Rechazado), `firmado` (documento firmado, con marcador de sello).
- El color nunca va solo: la palabra siempre dice el estado.
