Tarjeta de un mandato o expediente: referencia en `mono`, nombre en `display`, estado, descripción y un pie de cifras bajo un filete de latón.

- Provee: `<article class="cu-card">` con `.cu-card-head` (referencia, título, `cu-badge`), un párrafo y un `<dl class="cu-card-seal">` de dos a cuatro cifras.
- El filete de latón marca el bloque de cifras como el "sello" del documento: una vez por tarjeta.
- Para listas de más de seis elementos usá DataTable.
