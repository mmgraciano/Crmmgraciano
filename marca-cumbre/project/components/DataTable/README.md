Tabla de datos: encabezados en `label`, montos y porcentajes alineados a la derecha en `mono`, total con filete de latón.

- Provee: `<div class="cu-table-wrap"><table class="cu-table">` con `thead`, `tbody` y, si hay total, `tfoot`.
- Celdas numéricas con `num`; números de cuenta con `ref`; variaciones con `pos` o `neg` y siempre con signo (+ / −).
- Formato argentino: punto de miles, coma decimal, moneda adelante (USD 1.284.500,00).
